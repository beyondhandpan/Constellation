# MainStage setup

- 12 patches P0–P11 (6 Pigments, 6 Omnisphere). Add a Scripter MIDI FX to each with `scripter_v1_4.js`, changing only the `TAG` line.
- Only one patch is active at a time; CC28 on Ch 1 toggles the latch on the active patch.
- Keep three or fewer latched instruments to avoid cutouts with heavy reverbs.
