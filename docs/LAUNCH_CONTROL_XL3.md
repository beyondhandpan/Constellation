# Novation Launch Control XL 3 (optional)

Custom mode "Constellation 01": faders CC53–60 on Ch 3, buttons CC37–52 (Button 1 CC52 on Ch 3), knobs CC13–36.
After a power cycle the unit starts in Mode 16: press Mode, then select the Constellation slot.
Plug directly into the Mac, not a hub, and close Components when testing.
MainStage: hardware assignments are concert level; patch-level mappings override them.

Tempo and transport (concert level, MainStage Actions): bottom-right knob CC36 Ch 1 = **Tempo / Tap Tempo** (range 60-120); button above it CC44 Ch 1 = **Play/Stop**. See `MASTER_CLOCK.md`.
